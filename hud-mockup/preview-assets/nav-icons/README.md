# Preview navigation icons

These ten SVGs are browser-preview copies decompiled from the installed CS2
`pak01_dir.vpk` Panorama icon resources. The native addon references the
corresponding game-provided `s2r://panorama/images/icons/...vsvg` paths and
does not package these copies. The browser rendering is an approximation;
matching appearance in the retail client still requires native verification.

The V10 home fixture also uses browser-only decoded game textures for AK-47
Autoexec (definition 7, paint 1449) and Glock-18 AXIA (definition 4, paint
832), extracted from their matching native `default_generated` resources.
The fixture illustrates a saved selection; it is not a real player snapshot.
